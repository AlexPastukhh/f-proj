# Feature Projection planning

This directory separates durable design from the living execution roadmap.

- `MASTER-PLAN.md` — current status, next work units, acceptance criteria.
- `DECISIONS-AND-DELTAS.md` — empirical changes and decisions made after the original v11 pre-prototype design.
- The exact original v11 specification is preserved separately in the consolidated planning archive; it remains the architectural/specification layer rather than the active implementation sequence.

Reading order:

1. `MASTER-PLAN.md`
2. `DECISIONS-AND-DELTAS.md`
3. relevant v11 specification document for deeper rationale

Rule: do not silently rewrite historical assumptions. If prototype evidence changes an old assumption, record the change in `DECISIONS-AND-DELTAS.md` and update status in `MASTER-PLAN.md`.
